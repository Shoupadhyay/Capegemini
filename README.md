# C# Learning Journey

## Basics of C# Programming

In this session, I learned about fundamental concepts in C# programming:

### Integer Data Types
- Learned about the `int` data type for storing whole numbers
- Understanding integer variables and their declarations
- Example:
```csharp
int number = 42;
int age = 25;
```

### User Input Handling
- Learned how to take input from users using `Console.ReadLine()`
- Converting string input to integers using `int.Parse()` or `Convert.ToInt32()`
- Example:
```csharp
Console.Write("Enter a number: ");
int userNumber = Convert.ToInt32(Console.ReadLine());
```

### Key Concepts Covered
- Variable declaration and initialization
- Basic input/output operations
- Type conversion from string to integer
- Console application interaction
